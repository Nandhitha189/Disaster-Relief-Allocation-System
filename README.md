# Disaster Relief Resource Allocation and Aid Distribution System

## DBMS Level 3 Mini Project

### Team Members
- Rachepalli Nandhitha
- Raksha V

## Project Overview
A database-driven disaster relief management system designed
to manage disasters, relief centers, beneficiaries, resources,
aid requests, priority-based allocation, and aid distribution.

## Technology Stack
- Frontend: Next.js
- Backend: Next.js API Routes
- SQL Database: MySQL
- NoSQL Database: MongoDB Atlas
- Version Control: Git and GitHub

## Database Features
- Relational database design
- Primary and foreign keys
- Constraints
- JOIN queries
- Transactions
- Priority-based resource allocation
- Partial allocation
- Views
- Indexing
- Stored procedures
- Triggers
- MongoDB aggregation

## Project Structure
- database/mysql: MySQL schema and sample data
- database/mongodb: MongoDB scripts
- screenshots: Implementation evidence
- docs: Project documentation
- web: Next.js application (to be developed)
